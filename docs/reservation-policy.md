# 예약 정책 (Reservation Policy)

병원 예약의 생성·취소·노쇼 규칙 요약. 코드(`reservationPolicy.ts`)의
`ReservationPolicyConfig` 를 사람이 읽는 문서로 정리한 것이다.

## 예약 생성
- 최소 리드타임: 지금으로부터 **2시간** 이후부터 예약 가능
- 최대 예약 기간: **60일** 후까지 예약 가능
- 운영 시간: **10시 ~ 20시**

## 취소 위약금
진료 시작까지 남은 시간 기준:
- **48시간 이전**: 위약금 없음 (전액 환불)
- **24~48시간 전**: 20% 위약금
- **24시간 이내**: 50% 위약금

## 노쇼(No-show)
- 예약금 **전액(100%)** 몰수
